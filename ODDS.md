# Falling Animation — Spawn Odds

Every ambient drop rolls for a kind, then hearts roll for a colour or a rare special. The code is `ambientItem()` in `falling.js`.

## Per Drop

| Item | Chance |
|---|---|
| White petal | 45% |
| Green leaf | 15% |
| Blue heart | ~13.2% |
| Light blue heart | ~13.2% |
| White heart | ~13.2% |
| 💖 or 💝 | 0.4% |
| 💎 | 0.04% |

## Heart Breakdown (within the 40% that is a heart)

| Type | Chance |
|---|---|
| Blue / light blue / white (normal) | 98.9% |
| 💖 / 💝 | 1% |
| 💎 | 0.1% |

## Fun facts

- 💎 appears about **1 in 2,500** drops.
- 💖 / 💝 appear about **1 in 250** drops.
- 6 in 10 drops are the soft white petals and green leaves that set the mood.
- A drop falls roughly every 0.9 seconds, so a 💎 turns up about once every 40 minutes.
